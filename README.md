# 火柴人平台竞技 · Chaos gun fight 1.3.1

简约火柴人平台对战。用枪械和爆炸物把对手轰出地图，掉落扣命，最后存活者获胜。支持鼠标自由瞄准、弹匣换弹、武器空投、中文武器浮字、护盾、火箭飞行器、隐身装置、三种开局手枪、局域网双人对战和电脑练习。

## 开始

双击 **StickMayhem.exe**。推荐 Windows 10 / 11，使用系统 .NET Framework WPF，无需安装器、浏览器、Python或现代 .NET SDK。程序、所有数值、平台和图形内置于单个可执行文件。

一个人体验：选择开局武器、地图和生命数，然后点顶栏小 **test**。

两人联机：同一局域网，两人使用同版本程序，各自选好开局武器。一人点“创建房间”，复制完整 `IP:端口` 给另一人，对方填写后点“加入”。通过校验后自动开始。**地图和生命数采用房主选择；双方开局武器可以不同。**

默认端口 **42673**。Windows 防火墙提示时允许专用网络访问。失败时检查版本、地址、端口、防火墙和路由器设备隔离。支持私有 IPv4 直连，地址不带端口时使用右侧端口框；多网卡用地址旁小下拉切换。支持文字选择与 Ctrl+C，也有点击复制。

切到“连接”可以返回房间页，再点“返回项目”继续。点“离开”结束当前连接，再建房加入可重开。断线后结算和操作停止，重新建房，不自动转成人机或自动续局。

## 操作

| 操作 | 按键 |
| --- | --- |
| 自由瞄准 | 鼠标移动 |
| 连续射击 | 按住鼠标左键 |
| 投掷炸弹 | 鼠标右键，每次点击一枚 |
| 左右移动 | A / D 或方向键 ← / → |
| 跳跃、二段跳 | W / 空格 / ↑，按两次；有火箭飞行器时长按空格飞行 |
| 向下穿过平台 | S / ↓ |
| 最小化 | Esc |

在战场区域点击即可操作。枪口和弹道跟随鼠标，能向上、向下、斜向射击。双方看到相同方向的地图。切页、最小化、失去焦点和释放鼠标捕获时会清除移动和射击输入；对局仍继续。

## 手枪、换弹与空投

开局只能从三种手枪中选择：

- **左轮**：6 发弹匣，换弹 3 秒，单发，冲击与击退显著增强。
- **USP**：12 发弹匣，换弹 2 秒，单发，击退居中。
- **格洛克**：20 发弹匣，换弹 1.5 秒，击退最低，可按住左键连发。

三种开局手枪都有无限备弹，但弹匣打空后必须完成换弹。左轮和 USP 每次按下左键只发一枪；格洛克支持按住连发。重生和空投弹药用尽后恢复所选手枪。左上角显示“弹匣/备弹”，`∞` 代表无限备弹；换弹时显示剩余秒数，角色头顶的圆环同步显示换弹进度。

首个普通武器空投在 3 秒后到达，之后每 7–10 秒随机投放；首个大空投约在 18 秒后出现，之后每 28–36 秒出现。两种箱子都带降落伞，**大空投箱尺寸更大、带双层边框和“大”标记**。触碰立即拾取，场上最多 4 箱，过期箱 24 秒消失。拾取后角色头顶出现**中文名称**，向上漂移，后半段渐淡，约 1.65 秒后消失。

普通武器箱不含三种开局手枪或特殊武器，只会投放霰弹枪、狙击枪、火箭筒或榴弹发射器。霰弹枪增强为每次 6 颗散射子弹，单颗冲击力从 100 提高到 180；榴弹发射器有 12 发弹匣，发射有抛物线轨迹的爆炸榴弹，爆炸会击退范围内玩家。

特殊武器只由大空投箱掉落：加特林“**牢张的愤怒**”（60 发、15 秒）或近战武器“**坐牢之剑**”（15 秒）。持有任一特殊武器时，普通箱和其他大空投都不能替换它；箱子仍留在场上供其他玩家争夺。加特林保持极高射速和高击退；子弹打空或倒计时结束，持有者立即损失一条命。坐牢之剑挥击可命中前方近距离目标，命中立即扣除对手一条命，并附带 5 秒隐身（自己半透明、对手视角消失）；两种武器打空、命中或超时造成的死亡都会播放约 0.85 秒的火柴人碎裂动画。两把武器重生后都会切回开局手枪，头顶及 HUD 显示剩余时间。

## 护盾、火箭飞行器与隐身

增益补给每隔 **8–10 秒**随机刷新护盾、火箭飞行器或隐身装置之一，并用小型降落伞落到平台：

- **护盾**：持续 6 秒，抵挡普通子弹、火箭与炸弹造成的击退和冲击积累。
- **火箭飞行器**：没有持有时限；有 3 秒燃料，长按空格向上推进，松开不消耗，燃料耗尽后不能继续飞。重生后清除。
- **隐身装置**：持续 5 秒。持有者自己看到角色半透明，另一名玩家的画面中角色完全消失；碰撞和受击规则不变。

拾取时头顶同样显示中文名称，HUD 用“盾”显示剩余秒数，用“喷”显示剩余燃料。重生会清除当前增益。

普通子弹可穿平台，火箭碰平台或命中会爆炸，炸弹碰平台会弹跳。每条命有 3 枚炸弹。手投炸弹的爆炸范围和冲击力已增强；**爆炸能击退自己**，投掷和火箭使用时注意距离。

## 规则

- 3 张地图：分层平台、双桥断层、交错阶梯。
- 开局生命可选 3 / 5 / 7 / 10 命。
- 没有扣血死亡机制。命中累积冲击值并产生击退，冲击越高越容易被打飞；离开地图边界才扣命。
- 玩家头顶持续显示冲击百分比；角色飞出战场可视范围时，屏幕边缘会显示方向箭头，隐身的对手仍不会被箭头暴露。
- 重生等待约 1.1 秒，恢复开局武器、3 枚炸弹、0 冲击，并获得 1.8 秒保护。玩家从两条命掉到一条命后复活，头顶显示“背水一战”，随后上飘淡出。
- 两段跳、单向平台、下落穿平台、枪械散射、自动射击、弹跳炸弹、爆炸击退与空投争夺。
- 双方最后一命同时掉落为平局。
- 电脑会追击、瞄准、射击、二段跳、穿平台、投炸弹、使用火箭飞行器并争抢武器与增益。重复点 test 会按当前开局设置重开练习。

原作的核心是平台站位、跳跃与枪械击退。本作沿用这一机制，采用原创火柴人、地图与数值，并改为鼠标瞄准、局域网双人对战。未复制原作的贴图、音频或代码。

## 外观

沿用办公面板伪装：细网格、正常字重、小字号、低饱和颜色、无音乐。可选 WPS / Codex 浅色 / Codex 深色，普通 **548×474**、极简 **392×300**。深色主背景 `#0D1117`，前景 `#E6EDF3`。

窗口固定为 Windows 逻辑像素尺寸，系统缩放影响物理像素大小。战场保持宽高比，小窗口内坐标转换仍与鼠标对应。设置即时保存到同目录 `preferences.ini`，同时保存开局武器、地图和生命数；不保存对局。

## 联机技术

房主独立推进 60 Hz 物理，通常以 30 Hz 同步状态。客户端以 30 Hz 和关键按键/鼠标事件提交输入，不提交角色坐标、命中或武器修改。输入包括对局标识、递增序号、移动/射击/喷气状态、跳跃/炸弹/下落事件编号和鼠标世界坐标；房主统一计算碰撞、弹匣、换弹、空投、增益、燃料、击退和胜负。

子弹使用扫线检测，减少高速弹道穿过角色而漏判。客户端将相邻快照插值绘制，自己的枪口瞄准随鼠标立即变化；移动采用房主快照，有少量联机显示延迟。优先在稳定局域网使用。

开局校验协议、规则指纹和程序 SHA256，双方需使用同份可执行文件。TCP 后台传输、长度限制、心跳与超时处理，状态只由 WPF 主线程更新。失效输入超过半秒时停止持续射击或移动输入。仅两人对战，无公网服务器和匹配功能。

## 编译与验证

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
.\StickMayhem.exe --verify previews
```

编译使用 Windows .NET Framework 的 C# 编译器。验证在屏幕外执行真实 WPF 控件树渲染，不覆盖外观偏好或剪贴板。失败退出码为非 0，详情写入 `previews/error.txt`。

验证覆盖三种手枪的弹匣、精确换弹时间、头顶圆环、单发/连发差异，普通与大空投池、增强霰弹枪、榴弹发射器、加特林 60 发/15 秒、坐牢之剑近战即死和碎裂动画、特殊武器浮字，各武器和三张地图的完整电脑对战，以及全部原有联机、移动和增益规则。两套 WPF 界面使用真实 TCP 回环验证双方自选手枪、输入、瞄准射击、大空投/特殊武器、剑击碎裂、新增道具同步、版本拒绝和断线停用。

生成三种主题与两种尺寸的真实 WPF PNG，以及浮字出现 / 渐淡 / 消失三帧。实际报告见 `previews/verification.txt`、`verification.json` 和 `simulations.json`。

尚未在两台实体电脑间测试，尚未进行实体鼠标/键盘自动化验证；当前证据为模型、输入路径、双 WPF TCP 回环与真实控件树渲染。原作手感与数值并非逐项复刻。

## 文件

- `StickMayhem.exe`：双击运行。
- `StickMayhem-share.zip`：轻量分享包，发给另一名玩家，解压运行。
- `src/Game.cs`：规则、物理、武器、普通/大空投、AI 和碎裂效果状态。
- `src/Network.cs`：局域网协议和后台通信。
- `src/Drawing.cs`：火柴人、枪口、准星、大小空投箱、换弹进度环、剑击与碎裂动画、淡出文字。
- `src/Window.cs`：界面、输入、房间、外观和选择。
- `src/Verification.cs`：启动入口、语义测试、集成与预览。
