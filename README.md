# 火柴人平台竞技 · Chaos gun fight 1.7.5

简约火柴人平台对战。用枪械和爆炸物把对手轰出地图，掉落扣命，最后存活者获胜。支持鼠标自由瞄准、弹匣换弹、武器空投、中文武器浮字、护盾、火箭飞行器、隐身装置、三种开局手枪、最多六人局域网对战和电脑练习。

## 开始

解压完整更新包后双击 **StickMayhem.exe**。推荐 Windows 10 / 11，使用系统 .NET Framework WPF，无需浏览器、Python 或现代 .NET SDK。游戏主体内置于可执行文件；`StickMayhem.Update.exe` 仅在用户点击“安装重启”时替换程序。

一个人体验：选择开局武器、地图、生命数和模式，然后点顶栏小 **test**。练习人机会近身使用坐牢之剑、避开克莱博反冲造成的坠落风险；目标隐身时不再读取其实时位置，而会朝搜索区域试射。

局域网多人：最多 6 人使用同版本程序，各自选择开局手枪。房主点“创建房间”并分享完整 `IP:端口`；其他玩家依次加入，系统分配 2–6 号，房主为 1 号。至少 2 人到齐后，房主点“开始对战”。**地图、生命数和模式采用房主选择；普通模式下每人可选择不同开局手枪。**

默认端口 **42673**。Windows 防火墙提示时允许专用网络访问。失败时检查版本、地址、端口、防火墙和路由器设备隔离。支持私有 IPv4 直连，地址不带端口时使用右侧端口框；多网卡用地址旁小下拉切换。支持文字选择与 Ctrl+C，也有点击复制。

切到“连接”可以返回房间页，再点“返回项目”继续。点“离开”结束当前连接，再建房加入可重开。断线后结算和操作停止，重新建房，不自动转成人机或自动续局。

## 更新日志与版本更新

顶栏“更新日志”按版本折叠显示说明，右侧“版本更新”可检查 GitHub 上的最新包。检查使用仓库主分支的 `update.json`，并在 `raw.githubusercontent.com` 不可达时回退到 jsDelivr；下载后仍以 SHA-256 校验。**如果要让收到分享包的其他人匿名检查更新，GitHub 仓库必须设为 Public**，否则 GitHub 会对未登录访客返回 404。当前包地址为 `StickMayhem-share.zip`。

下载包后，游戏先校验清单中的 SHA-256。点击“安装重启”后，独立更新器等待游戏进程退出，再替换主程序与说明文件；`preferences.ini` 等用户数据不在包内，会保留。安装失败时会用暂存副本恢复旧文件。对局或房间未退出时不可安装；可以先检查、下载，结束对局后再安装。

初次安装或手动更新：从 GitHub 仓库下载 `StickMayhem-share.zip` 并解压整个包。之后可在程序内检查并安装新版本。

## 手枪、换弹与空投

开局只能从三种手枪中选择：

- **左轮**：6 发弹匣，换弹 3 秒，冲击与击退显著增强；按住左键可持续发射，射速较慢。
- **USP**：12 发弹匣，换弹 2 秒，击退居中；按住左键可持续发射，射速适中。
- **格洛克**：20 发弹匣，换弹 1.5 秒，击退最低，可按住左键连发。

三种开局手枪都有无限备弹，但弹匣打空后必须完成换弹。左轮、USP 和格洛克都可按住左键连续射击，各自按射速间隔发弹；重生和空投弹药用尽后恢复所选手枪。左上角显示“弹匣/备弹”，`∞` 代表无限备弹；换弹时显示剩余秒数，角色头顶的圆环同步显示换弹进度。

首个普通武器空投在 3 秒后到达，之后每 7–10 秒随机投放；首个大空投约在 18 秒后出现，之后每 28–36 秒出现。两种箱子都带降落伞，**大空投箱尺寸更大、带双层边框和“大”标记**。触碰立即拾取，场上最多 4 箱，过期箱 24 秒消失。拾取后角色头顶出现**中文名称**，向上漂移，后半段渐淡，普通拾取约 1.65 秒后消失。

普通武器箱不含三种开局手枪或大空投武器，会投放霰弹枪、狙击枪、火箭筒、榴弹发射器、突击步枪、普通冲锋枪或**电能冲锋枪**。霰弹枪每次 6 颗散射子弹，单颗冲击力为 180；榴弹发射器有 12 发弹匣，发射抛物线爆炸榴弹，触碰敌人时立即引爆。**火箭筒**的爆炸范围和击退显著加强，爆炸会产生扩散冲击环、中心闪光和火焰碎光，也会波及自己。狙击枪的单发冲击力小幅提高。突击步枪点按一次触发三连发，三发短促射出后有间隔，冲击力略微提高；每条命只有 30 发，打完切回开局手枪。普通冲锋枪同为 30 发总弹量。电能冲锋枪为 30 发总弹量、没有备用弹匣，蓝色子弹，击退力与格洛克相同、冲击值增幅略低于普通冲锋枪；命中会令目标移动速度和跳跃强度降低 70%，持续 2 秒。

**跳狙飞人**是连接页可选模式：双方开局持有克莱博，重力为普通模式的 50%，因此跳得更高；克莱博无限子弹，但每发后仍需 1 秒枪机周期。此模式没有普通或大型武器空投箱，只刷新地图增益道具。联机由房主选择模式，选择后全房间同步。

**军备竞赛**：所有人从狙击枪开始，每把武器需击杀两次后升级，最后的坐牢之剑击杀一次即可获胜。顺序为：狙击枪 → 克莱博 → 霰弹枪 → 火箭筒 → 榴弹发射器 → 突击步枪 → 冲锋枪 → 电能冲锋枪 → 专注冲锋枪 → 加特林 → 左轮 → USP → 格洛克 → 坐牢之剑。所有玩家无限命，死亡或出界后会重生；意外死亡没有明确攻击者时会计给最近的对手；不刷新武器空投或地图道具，弹药可以无限补充。联机以房主选择为准。

除三种开局手枪外，枪械开火会产生物理后坐力；HUD 显示 0–5 级。霰弹枪 2 级、狙击枪与火箭筒 3 级、加特林 2 级、榴弹发射器 1 级、突击步枪 2 级、普通/专注冲锋枪 1 级、克莱博 4 级、电能冲锋枪 0 级。补给道具出现后 5 秒未被拾取会闪烁 2 秒，随后消失。

特殊武器只由大空投箱掉落，共四种：加特林“**牢张的愤怒**”（60 发、15 秒）、近战“**坐牢之剑**”（15 秒）、**专注冲锋枪**（45 发）和**克莱博**（5 发）。持有任一大空投武器时，普通箱和其他大空投都不能替换它；箱子仍留在场上供其他玩家争夺。加特林保持极高射速和高击退；子弹打空或倒计时结束，持有者立即损失一条命。坐牢之剑挥击可命中前方近距离目标，命中立即扣除对手一条命，并附带 5 秒隐身（自己半透明、对手视角消失）。专注冲锋枪以蓝色能量弹射击，持续按住左键时射速从慢逐渐加快，松开后重新蓄速。克莱博每发之间有 **1 秒枪机装填**；命中后直接击杀并播放碎裂动画，强烈后坐力会将射手向后震飞，头顶持续显示剩余弹数。专注冲锋枪和克莱博打空后切回开局手枪；两把限时特殊武器打空或超时的死亡也会播放约 0.85 秒碎裂动画。

## 护盾、火箭飞行器与隐身

增益补给每隔 **8–10 秒**随机刷新护盾、火箭飞行器、隐身装置或速度道具之一，并用小型降落伞落到平台：

- **护盾**：持续 6 秒，抵挡普通子弹、火箭与炸弹造成的击退和冲击积累。
- **火箭飞行器**：没有持有时限；有 3 秒燃料，长按空格向上推进，松开不消耗，燃料耗尽后不能继续飞。重生后清除。
- **隐身装置**：持续 5 秒。持有者自己看到角色半透明，另一名玩家的画面中角色完全消失；碰撞和受击规则不变。
- **速度道具（速）**：持续 5 秒，移动速度和射速翻倍；头顶白色“火力全开”文字及秒数持续闪烁，HUD 显示增益倒计时。

拾取时头顶同样显示中文名称，HUD 用“盾”显示护盾秒数，用“喷”显示燃料，用“速”显示速度增益剩余时间。重生会清除当前增益。

普通子弹可穿平台，火箭碰平台或命中会爆炸，炸弹碰平台会弹跳。每条命有 3 枚炸弹。手投炸弹的爆炸范围和冲击力已增强；**爆炸能击退自己**，强化后的火箭爆炸冲击更大，注意距离。

## 规则

- 6 张大地图：分层平台、双桥断层、交错阶梯、风车中庭、断桥高台、环形回廊；每张地图都有 6 个独立出生点。
- 开局生命可选 3 / 5 / 7 / 10 命。
- 没有扣血死亡机制。命中累积冲击值并产生击退，冲击越高越容易被打飞；离开地图边界才扣命。
- 冲击值最高为 250%；满值后每次再受击有 20% 概率直接死亡并重生。
- 玩家头顶持续显示冲击百分比；角色飞出战场可视范围时，屏幕边缘会显示方向箭头，隐身的对手仍不会被箭头暴露。
- 重生等待约 1.1 秒，恢复开局武器、3 枚炸弹、0 冲击，并获得 1.8 秒保护。玩家从两条命掉到一条命后复活，头顶显示“背水一战”，随后上飘淡出。
- 两段跳、单向平台、下落穿平台、枪械散射、自动射击、弹跳炸弹、爆炸击退与空投争夺。
- 双方最后一命同时掉落为平局。
- 电脑会追击、瞄准、射击、二段跳、穿平台、投炸弹、使用火箭飞行器并争抢武器与增益。重复点 test 会按当前开局设置重开练习。

原作的核心是平台站位、跳跃与枪械击退。本作沿用这一机制，采用原创火柴人、地图与数值，并改为鼠标瞄准、最多六人的局域网混战。未复制原作的贴图、音频或代码。

## 外观

沿用办公面板伪装：细网格、正常字重、小字号、低饱和颜色、无音乐。可选 WPS / Codex 浅色 / Codex 深色，普通 **548×474**、极简 **392×300**。深色主背景 `#0D1117`，前景 `#E6EDF3`。

窗口固定为 Windows 逻辑像素尺寸，系统缩放影响物理像素大小。战场保持宽高比，小窗口内坐标转换仍与鼠标对应。设置即时保存到同目录 `preferences.ini`，同时保存开局武器、地图、生命数和对战模式；不保存对局。

## 联机技术

房主独立推进 60 Hz 物理，通常以 30 Hz 同步状态。客户端以 30 Hz 和关键按键/鼠标事件提交输入，不提交角色坐标、命中或武器修改。输入包括对局标识、递增序号、移动/射击/喷气状态、跳跃/炸弹/下落事件编号和鼠标世界坐标；房主统一计算碰撞、弹匣、换弹、空投、增益、燃料、击退和胜负。

子弹使用扫线检测，减少高速弹道穿过角色而漏判。客户端将相邻快照插值绘制，自己的枪口瞄准随鼠标立即变化；移动采用房主快照，有少量联机显示延迟。优先在稳定局域网使用。

开局校验协议、规则指纹和程序 SHA256，所有玩家需使用同份可执行文件。TCP 后台传输、长度限制、心跳与超时处理，状态只由 WPF 主线程更新。失效输入超过半秒时停止持续射击或移动输入。最多六人局域网对战，无公网服务器和匹配功能。
